swat.glb is a runtime conversion of the user's supplied Ch15_nonPBR.fbx, downloaded from Adobe Mixamo.
The original file is preserved in the project root. This conversion retains the character's textures and skin rig.
Body geometry is simplified for real-time rendering; the first-person arms derive from the same source.
