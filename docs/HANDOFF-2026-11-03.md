# Game backup — 2026-11-03

Current playable game, Villa Solstice and training map, Pose Studio, runtime assets,
material destruction/physics fixes, bathtub blast correction, conversion scripts,
and tests. Original main history is preserved on a separate backup branch.

## Run

Use Node.js 22. Run `npm ci`, then `npm run dev` and open the URL Vite prints.
Open `/studio.html` for Studio and `/?map=training` for the training map.
Run `npm test` and `npm run build` for validation. Latest checks: 249 tests passed.

## Separate browser data

Custom Studio poses live in browser localStorage (`fast-snipe-poses-v1`), not Git.
Export JSON from the owner's existing Studio tab and import/save it on the next
machine. Browser access was disabled during backup, so these presets could not be
exported automatically. Existing local presets have not been changed.

## Scope

Includes runtime models, animation/audio banks, textures and the current sources.
Excludes node_modules, dist, temporary artifacts, unused experimental asset packs,
and the three oversized original FBX/ZIP packs. The converted runtime assets are
included; those originals are not needed to run the game.

Multiplayer networking is not implemented yet. Preserve the existing fixed-size
fragment pools, physics sleeping, worker scheduling and loading-screen shader
warmup when making changes. See docs/destruction-performance.md for details.

Encoding caution: src/main.js and README.md contain legacy non-UTF-8 bytes;
preserve their encoding rather than rewriting them indiscriminately.
